# 设计令牌（绿色系 + 模型品牌色）

> 唯一色源：`src/tokenboard/brands.py`。
> 改这里必须同步：`render.py` 的 CSS 变量映射、Ardot 绿色版设计稿、本文件。
> 上次同步：2026-11-05。

## 1. 两条正交规则

1. **绿色系只用于 UI 框架**：背景、卡片、边框、文字、主按钮、热力色阶。
2. **品牌色只用于数据系列**：图表柱/线、图例点、模型徽标；且必须附文字标签。

这样"UI 统一绿色系"和"不同模型匹配品牌色"不会互相打架。
OpenAI 品牌绿 `#10A37F` 与主色接近，因此所有数据色块额外带 1px 深色描边 +
文字标签双重区分（WCAG 1.4.1）。

## 5. 可访问性核对

- 正文对比度 ≥ 4.5:1；大数字 ≥ 3:1；主色 `#1F6F63` 对白 5.9:1，可用作文字。
- 模型区分不依赖颜色：图例、条形、表格都带模型名与厂商名。
- 热力图附四时段百分比文字替代表，读不到颜色也能得到结论。
- 数值不依赖 hover 才可见（tooltip 只是补充）。
