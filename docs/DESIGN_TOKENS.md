# 设计令牌（绿色系 + 模型品牌色）

> 唯一色源：`src/tokenboard/brands.py`。
> 改这里必须同步：`render.py` 的 CSS 变量映射、Ardot 定稿设计稿（fileId `744241768816105`：浅色版 `2:224` / 暗夜玻璃深色版 `2:124`）、本文件。
> 上次同步：2026-11-06（对齐定稿设计稿，浅色为默认主题）。

## 1. 两条正交规则

1. **绿色系只用于 UI 框架**：背景、卡片、边框、文字、主按钮、热力色阶。
2. **品牌色只用于数据系列**：图表柱/线、图例点、模型徽标；且必须附文字标签。

这样"UI 统一绿色系"和"不同模型匹配品牌色"不会互相打架。
主题强调色在白底上不作正文色：浅色主题的强调文字由 `brand_bright`（深绿）承担，
荧光绿只做填充 / 徽标 / 选中态（WCAG 1.4.1）。

匹配规则：模型名小写后按**有序前缀**匹配（`BRAND_COLORS` 的声明顺序即优先级，
长前缀在前）。未命中走绿色阶，且同模型永远同色。

**同厂商撞色阶梯**：同一品牌色出现第 2、3… 个模型时按 `COLLIDE_SHADES`
（0 / −50% / −68% / −78% / −85%）依次**压暗**——白底看板上变暗比提亮更可读
（例：`hy4-free=#00E5A0`、`hy3≈#007250`）。

## 5. 看板信息架构（v0.2 定稿）

1. 结论条（本期结论 + 折合单价 + 覆盖提示）
2. KPI 行：合计 Token / 请求轮次 / 缓存命中率 / 预估金额
3. **01 补充指标 · 原统计口径**：日均（有数据天）/ 会话 / 输入输出比
4. **02 模型与品牌色**：按模型消耗（+口径行）｜每日用量趋势（堆叠柱）
5. **03 数据源状态与口径**：平台表（已验证 / 未验证）+ 连接状态点
6. **04 使用分布与时间节律**：工作空间活跃分布（可搜索/排序）→ 单模型总量统计
   （按 Token / 按金额 切换、周期跟随全局时间窗口）→ 0—24 时分布·按模型 →
   单次请求大小分布（p50/p90 + 全局 50% 基准线）→ 日活分布（时段占比 + 日×时热力图）

时间窗口由 CLI `--since`（如 `7d`）决定，页面顶部周期胶囊只作状态展示，
所有模块同源同窗，空窗日不参与日均。

## 6. 可访问性核对

- 正文对比度 ≥ 4.5:1；大数字 ≥ 3:1；浅色强调文字用 `#075C42`（对白 8.6:1），
  荧光绿 `#00E5A0` 仅用于填充类元素，不承载正文。
- 模型区分不依赖颜色：图例、条形、表格都带模型名与厂商名。
- 热力图附四时段百分比文字替代表，读不到颜色也能得到结论；每个色块带 title 数值。
- 数值不依赖 hover 才可见（tooltip 只是补充）。
